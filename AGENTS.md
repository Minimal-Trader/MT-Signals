# MT-Signals

Remotion renderer for Minimal Trader trade-replay videos (1080x1920, TikTok/Reels/Shorts).

## Brand naming: MT vs Minimal Trader
- "MT" is the shorthand mark: logo, corner chrome, tight UI spaces. Fine as-is there.
- In long-form contexts (voiceover narration scripts, titles, descriptions, any copy with room), use the full name "Minimal Trader", not "MT". Shorthand is allowed once the full name has been established in the same piece.
- Never let every mention collapse to "MT": the audience should always be able to connect the MT mark back to Minimal Trader.

## Visual direction
- Light mode first, always: white background, ink #111827, orange #ff5a00 (brand tokens in templates/brand.tsx; orange taken from the MT-Designs logo assets). No dark variants, no palette swaps; every concept and style pack must live in this system.
