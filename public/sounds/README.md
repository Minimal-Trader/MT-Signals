# Alert chime pool

Every audio file in this folder joins the per-trade rotation (deterministic on
trade id, same mechanism as voices, copy angles and music). The picked chime
plays at 1s into the video at volume 0.6 (`scripts/voiceover.mjs`,
`rotated('sounds', ...)`).

Currently curated mp3s from Pixabay contributors (universfield, dragon-studio,
soynoviembre, ...) — Pixabay license, commercial social use OK, no attribution
required. Drop in any other short licensed chime (`.mp3`/`.wav`/`.m4a`/`.ogg`)
and it joins the rotation; delete ones you don't like.

More candidates: https://pixabay.com/sound-effects/search/notification/
